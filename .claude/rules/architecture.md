# Architecture — invariants digest

Always loaded. One entry per invariant: the rule, the non-obvious reason, where it lives. **The full text of each — reasoning, measurements, incident history — is `docs/architecture.md`; read the matching entry before changing code an invariant names.** Numbering is shared with that file and permanent (code comments cite `invariant #N`).

## Stack

| Component | Technology |
|---|---|
| Runtime | Electron 33 · electron-store 8 · electron-builder 24 |
| System audio | ScreenCaptureKit helper `native/sck-audio-capture` (macOS 13+) — **no fallback** |
| Mic | sox |
| Transcription | Parakeet (`parakeet-mlx` via `uvx`, default) → whisper.cpp fallback (`services/transcriber.js`) |
| Summarisation + filing LLM | `runLLM` over `services/llmProviders.js` — `auto` = Codex CLI → Claude CLI → Ollama |
| Calendar | cxmail's SQLite (read-only) → EventKit helper `native/calendar-helper` |
| Slides (opt-in) | `native/sck-slide-capture`, a separate process |
| Call audio (opt-in) | `native/call-audio-tap`, a separate process: Core Audio tap of `avconferenced` |

## Where things live

- `main.js` — Electron main: IPC, recording orchestration, tray + panel, every guarded start/stop path. Kept thin; logic goes into pure modules.
- `services/` — mostly **pure, Electron-free, injectable fs/timers**, each with a sibling `*.test.js`. Capture: `recorder.js` (`Recorder` single-track + `DualTrackRecorder`), `levelMonitor.js`, `signalWatcher.js`, `silenceWatcher.js`, `captureProbe.js` + `probeRunner.js`, `processRegistry.js`, `slideCapture.js`, `callCapture.js`. Processing: `transcriber.js`, `transcriptMerger.js` (incl. mic-bleed suppression), `companionCoverage.js` + `companionTranscript.js`, `summariser.js`, `meetingContextBlock.js`, `speakerNames.js`, `slideText.js`, `markers.js`, `silentTrackNotice.js`. Filing: `noteFiler.js`, `vaultLocator.js`, `vaultProfile.js`. Calendar: `calendarSuggester.js`, `meetingDetector.js`, `dismissalRegistry.js`, `meetingFilter.js`, `meetingTemplate.js`, `preparedMeetingStore.js`, `calendarSources/`. UI models: `trayMenu.js`, `noteMenu.js`, `recordingsList.js`, `settingsSchema.js`, `dependencies.js`, `glass.js`.
- `renderer/` — settings window (`index.html`, `app.js`, `styles.css`) plus one HTML per floating window (menu-bar panel, meeting banner, pre-record, silence prompt, filing prompt), each with its own `preload-*.js`. `presenters.js` / `panelPresenters.js` are pure and **dual-loaded**: a plain `<script>` (there is no bundler) that also sets `module.exports`, so `node --test` loads the same file.
- `mcp/` — standalone stdio MCP server, no Electron, no ports (#12). `shared/paths.js` — frozen paths both processes agree on.
- `utils/` — `binaries.js` (#20), `audioDevices.js`, `audioProcessing.js`.
- `npm test` = the British-English gate (`scripts/check-british-english.js`, as `pretest`) + `node --test '**/*.test.js'`.

## Critical Invariants (DO NOT BREAK)

A rule belongs here if breaking it fails in a non-obvious way, it isn't self-evident from the code, and it applies codebase-wide.

1. **System audio is ScreenCaptureKit and nothing else — fail loudly, never record silence.** `resolveSystemCaptureMethod()` has one success case and three throws, each naming one fix (build the helper → `npm run build:native` / grant Screen Recording / needs macOS 13+). Mid-flight, a capture that delivers nothing **warns and keeps recording** (`watchSckStartup` → `sckSilentWarning()`, track marked `silent`); it never switches method. Health is measured on **samples, not file growth** — a zero-filled WAV grows at the byte rate of speech (gotcha #16): `LevelMonitor._readPeak` (tri-state; `null` is never evidence of silence) → `signalWatcher.js` live, `measureWavPeak` at processing time. The passive verdict needs mic corroboration, so it covers **dual-track only**; the active probe (#23) covers both modes. The filter shape is `excluding` because that is what *measured* non-zero (gotcha #15); `--filter-shape including` is a diagnostic, never auto-selected. `manifest.captureMethod` is always `'sck'` (`'blackhole'` only on sessions before 2026-08-10). **Do not re-add a fallback** (gotcha #2): the requirement is "never silently record nothing", not "always record something".
2. **Session directory contract**: `recordings/{timestamp}_session/` holds `manifest.json`, `system.wav`, optional `mic.wav`; the manifest drives all downstream processing. `services/fileManager.js`.
3. **Every spawned child is registered** via `registerProcess()` (`main.js`) and drained on quit (#21). Orphaned sox records forever and starves the next session's mic (gotcha #4).
4. **British English everywhere** (summariser, organisation, colour, behaviour). Enforced by the `pretest` gate.
5. **Privacy-first**: transcription is fully local; summarisation and filing go only through the user's own authenticated CLIs (`runLLM`), never a third-party service they haven't set up. `llmProviderStrict` exists so choosing the local provider can't escalate a transcript to a cloud CLI (#19).
6. **Store defaults live in `main.js`**: mode `'dual'`, labels `'Remote'`/`'Me'`. Changing one changes every user without a saved preference.
7. **The Calendar prompt comes from the `calendar-helper` binary** on its first `EKEventStore` access — not from Electron, not at launch. The suggester requests once, self-disables on denial, and never loops the helper against a denied state. `macOSCalendarSource.js` → `ensurePermission()`; IPC `calendar:requestPermission`.
8. **One dismiss state**: every banner dismissal goes through `DismissalRegistry` (`isDismissed()` / `dismiss({kind, expiry})`). The meeting detector and calendar suggester share it by occurrence fingerprint, so dismissing the pre-meeting banner suppresses the in-meeting one and vice versa.
9. **One idempotent stop path**: tray, `recording:stop` IPC, panel, silence prompt and the silence grace timer all route through `stopRecording()` (`main.js`), guarded by `stopInProgress`. Divergent stop paths drift, and a double stop orphans capture processes.
10. **Silence auto-stop is per-track and never silent.** Each poll classifies every track `live` (grew) / `unknown` (stalled < 120 s) / `ended` (≥ 120 s). `SilenceWatcher` judges only `live` tracks; any `unknown` pauses the decision; all-`ended` counts as silence. Every path goes prompt → 60 s grace, never a silent stop. `LevelMonitor`'s `0` can mean a read failure, which is why growth classification, not raw levels, gates it. `silenceWatcher.js` → `classifyTrackGrowth()`, `update(levels, {trackHealth})`.
11. **No recorder reinit mid-recording**: `settings:update` skips `initRecorder()` while `isRecordingActive()`; recorder settings apply on the next start. Swapping recorder references mid-capture orphans the live processes.
12. **The handoff directory is the ONLY app ↔ MCP channel.** `~/Library/Application Support/CXNotes/handoff/prepared`, computed by `shared/paths.js` — never `app.getPath` (dev and packaged names differ). The MCP server only reads calendars and stages (atomic tmp + rename); the app only reads and claims (`rename .json → .applied`); the suffix `.json` / `.applied` / `.cancelled` is the state. The MCP never drives a recording, and this state never goes through electron-store. Both sides build templates from `meetingTemplate.js`.
13. **The skeleton is a sibling file; the manifest stays flat.** `<sessionDir>/meeting-skeleton.md` carries the rich template (the AI summary still lands in `notes.md`); only `{title, participants, agenda}` reaches `manifest.json`. Gated on dual-track, since system-only has no session directory. `writeMeetingSkeleton()`, `renderSkeletonMarkdown()`.
14. **cxmail is the primary calendar source — read-only — with EventKit as the automatic fallback.** `calendarSource: 'auto'` (default) uses cxmail's DB when present, via `/usr/bin/sqlite3 -readonly -json` (registered; never write), else EventKit; `'cxmail'` / `'macos'` force one. cxmail stores one row per invite × mailbox, so the source normalises: dedup on `event_uid` (null-UID `detected` rows fall back to `summary|floor(startMs/60000)`), newest `created_at` wins, attendees union across REQUEST + REPLY rows, titles and descriptions cleaned, rooms dropped, UTC / floating / TZID resolved in JS. Eligibility is by provenance (`ics`, or `detected` at ≥ `cxmailCalendarMinConfidence`, default 0.7), and events carry `meetingWorthy: true` to skip the ≥2-attendee gate. The fingerprint is per dedup group. EventKit's roster is merged in additively (gotcha #21); the date and dedup traps are gotcha #9.
15. **The menu-bar panel is a VIEW, never a second source of truth.** It reads a snapshot via `panel:getState` and pushes on `panel:state`, and every action routes through the existing guarded paths (`handleStartRecording()`, `stopRecording()`, `startFromUpcoming()`). Menus are data built in main (`trayMenu.js`, `noteMenu.js` — the renderer invents nothing). `tray.setContextMenu()` is deliberately unused because it swallows left-click; `panelClosedAt` guards the blur-before-click re-open.
16. **Markers hit disk the moment they're dropped** (`<sessionDir>/markers.json`) and are folded into `manifest.markers` *from disk* at process time, so a crash keeps them and a reprocess picks them up. An empty list renders an empty prompt block, keeping marker-free prompts byte-identical. No-op in system-only mode. `services/markers.js`.
17. **The vault directory is resolved, never a literal — and null is valid.** `getVaultDirectory()` (app) / `resolveVaultDirectoryForScript()` (scripts). Null → notes stay in the recordings folder and the export is skipped. `vaultDirectory` is deliberately absent from store defaults so `store.has()` separates "never configured" (detect: legacy `~/Documents/CX` → Obsidian's own registry → `''`) from "cleared on purpose" (never re-detect). `vaultLocator.js` knows no personal paths.
18. **Glass is native vibrancy + tint, and no pane paints on another pane.** Every window sets Electron `vibrancy` (`GLASS.popover` / `GLASS.window`, `visualEffectState: 'active'`); `backdrop-filter` can't see past a window and is never the answer. `html` / `body` / wrappers paint nothing; each pane paints `rgb(var(--surface-x) / var(--alpha-y))` from the one `windowTransparency` dial via `services/glass.js` (`chrome ≤ pane ≤ card` at every position), stamped inline on `<html>` by `applyGlass()`. Triplets are **space-separated** — a comma list makes the declaration invalid, which paints nothing and looks like excellent glass (gotcha #13). Popovers invert density (thin field, dense bars). `--bg-input` / `--bg-elevated` stay opaque.
19. **The LLM provider is resolved from one registry, never hard-coded.** `services/llmProviders.js` (`PROVIDERS`, `AUTO_ORDER`, `resolveProviderOrder`) is the only place a provider is named. `auto` is the default and keeps the pre-setting Codex → Claude order exactly, with Ollama after (own test — upgrades must not switch provider). A named preference goes first with the rest behind it; only `llmProviderStrict` removes the fallback. An unknown stored value degrades to `auto` on read and write. Every entry point threads the same options: `llmOptions()` read fresh per call, `filingRunLLM`, `readStoredLlmOptions()` for scripts. A blank model override is stored as absent. Custom models widened gotcha #12.
20. **External binaries are resolved to absolute paths, never invoked by bare name.** No `which`, no `spawn('sox')`: use `utils/binaries.js` `resolveBinary()` ($PATH first, then Homebrew, `/usr/local/bin`, MacPorts, `~/.local/bin`, every nvm bin). A Dock-launched app gets `/usr/bin:/bin:/usr/sbin:/sbin`, and launching from a terminal hides that (gotcha #14). Large assets (the whisper model) live in `~/Library/Application Support/CXNotes/models`; repo-relative paths are dev-only.
21. **Quit drains its children.** `before-quit` defers (`preventDefault()` + a `shutdownStarted` guard) and `processRegistry.shutdown()` does SIGTERM → 2 s grace → SIGKILL, and always resolves. The grace lets the SCK helper finalise its WAV header. `proc.killed` only means a signal was *sent*; `hasExited()` reads `exitCode` / `signalCode`.
22. **A system-capture restart never touches the mic, writes a NEW file, and stitches with a padded gap.** Same SCK method, so not a fallback. `restartSystemCapture()` signals only `systemProcess`. Parts are `system.wav`, `system.part2.wav`, … and are never deleted. `planStitch()` derives each part's start backwards from when it stopped and pads every gap, because the merger orders on each file's own offsets. Re-check ownership (`_canOwnNewCapture()`) *after* draining the old helper, or a stop landing in that window orphans the replacement. When only one part holds audio it is promoted to `system.wav`, and `_replaceSystemFileWith()` undoes a half-done swap. Limits: `SYSTEM_RESTART_MAX` (2), 30 s apart, never while stopping. A restart must re-arm `SignalWatcher`, clear the track's growth entry and `retargetTrack()` the `LevelMonitor` (all three). Single-track has no restart path: a stream death ends that recording, and the recorder warns.
23. **The capture is PROVEN by playing a known sound into it, and a probe decides only when the capture is quiet.** `captureProbe.js` (pure) + `probeRunner.js` play a two-tone signature via `afplay` and detect it in the captured samples, at start (both modes) and before acting on any `SignalWatcher` verdict. `verifyCapture` checks for real audio first (`AUDIO_PROOF_PEAK`) and never consults the probe on a loud capture; that gate is what makes its noise and masking weaknesses harmless. It has three verdicts, `alive` / `dead` / `inconclusive`, and inconclusive (couldn't play, too faint) is never rounded into a verdict. A dead verdict at start is re-probed once. Amplitude is politeness (SCK taps ahead of the master volume), and the user's output is never muted. Losing the probe falls back to the previous inferred behaviour. Gotcha #17.
24. **Frame capture is scoped to ONE window — never a display, never an application.** `SourceResolver` (`native/sck-slide-capture/`) resolves the meeting audio's owner to one `SCWindow`, and `SCContentFilter(desktopIndependentWindow:)` is the only filter shape built, so other apps are never in the frame. Refusal (ambiguous, backgrounded, untitled browser window) is the common case and is recorded in the manifest. The one widening is the share case, latched at share-start to the window being presented FROM. It runs as a separate process from audio so slides can't endanger #1, and it is off by default (`slideCaptureEnabled`). Gotcha #20 (SCK frames).
25. **Vault filenames are `<CATEGORY> <Who|Topic> <MM.DD.YY>.md`, ≤ 40 chars.** The category derives from the destination folder. The `Meetings/` catch-all may earn one from content (`categoryForContent`) and otherwise gets **no prefix**: there is no default code. Folder codes, content codes and the user's own names come from the vault profile (`vaultProfile.js`, the `vaultProfile` setting; scripts use `readStoredProfile()`), never from a literal. The user is never named. The date is last and never truncated. The compression ladder ends in truncating the topic (`truncateMiddle`), and the literal `Meeting` fills only an empty middle. A note that moves folders is re-stamped (`restampCategoryForDestination`). `summariser.js` → `buildObsidianFilename()`.
26. **Call audio is ADDITIVE — a session with no call is left exactly as ScreenCaptureKit wrote it.** Phone and FaceTime calls are played by `avconferenced`, which SCK cannot hear (gotcha #24). `native/call-audio-tap` is its own process, started last, registered for the quit drain; it only polls the daemon's running-output flag and builds a tap (per-process, `.unmuted`, tap-only private aggregate) only while it plays — never during Meet/Zoom (measured). `planCallMix` returning `[]` means nothing is touched; otherwise `system.wav` → `system.sck.wav`, the mix lands at `system.wav` on the MIC's clock (the merge treats both tracks' sample 0 as one instant), with `-D` so samples outside the call stay bit-identical. Off by default; enabling it requests System Audio Recording outside a meeting. `services/callCapture.js`, `recorder.js` → `_finishCallAudio()`.

## Key flows

- **IPC**: `ipcMain.handle()` ↔ `ipcRenderer.invoke()`; each window's preload exposes its API through `contextBridge.exposeInMainWorld()`.
- **Recording**: preflight (sox, SCK, mic, LLM provider) → `DualTrackRecorder` (SCK helper + sox mic) → probe at start (#23) → stop via `stopRecording()` → `transcribeSession()` per track, or a companion transcript checked against CXNotes' own `mic.wav` (gotcha #23) → `transcriptMerger` → `generateSessionNotes()` via `runLLM` → `fileAndExportNotes()`. The summarise → file → manifest tail is `summariseAndFileSession()`, shared by process, re-summarise (`resummariseSession()`, which reuses the transcript) and full reprocess.
- **Calendar → 1-click record**: the MCP can stage a prepared meeting ahead of time, with the app closed (#12). When a detected or suggested call has a calendar event and `calendarAutoTemplateEnabled` is on, `decideBannerMode()` returns `'confirm'` → a single **Record** → `meeting:confirmRecord` → `buildMeetingContext` → `recordDismissal` (#8) → best-effort `preparedMeetingStore.claim` → `startRecordingWithContext` → skeleton (#13). The tray's *Upcoming* list (12 h horizon, `MENU_WINDOW_MINUTES`, ≤ 5) clicks through `startFromUpcoming()`, which mirrors that path exactly. MCP calendar permission: gotcha #8.
- **Menu-bar panel**: left-click opens it and right-click opens the full context menu. Idle shows Start, the next meeting and recent notes with the folder each was filed into. Recording shows timer, real level history, per-track health (a stalled track shows red *during* the meeting), markers and Stop. `⌘⇧M` drops a marker and is registered only while recording. Positioning: gotcha #10.
- **Opening a file** (`openArtefact()`): markdown inside the vault → Obsidian via `obsidian://open?path=`; markdown outside it → `plainTextEditor` (default TextEdit); anything else → `shell.openPath`. `isInsideVault()` tries logical containment first, then realpath (the vault symlinks client folders), on a path-segment boundary.
- **Vault auto-filing** (`services/noteFiler.js`, pure): (1) deterministic scoring (keyword in title +3, in participants/agenda +1.5, rule person +2, attendee overlap with existing filenames capped at +2), which routes at score ≥ 4 and a margin ≥ 2; (2) otherwise `runLLM` picks from the top 5 + `none`, with a 90 s race, a strict single-JSON contract and confidence ≥ 0.6; (3) otherwise, with some evidence, `Inbox/` + a triage pop-up, or with none, the `Meetings/` catch-all (no pop-up). Destinations are the `vaultFilingRules` setting (no built-in rules) plus auto-discovered `<parent>/<name>/<subdir>` for the profile's `discoveryGroups`. **Notes are never lost to filing**: any throw → the legacy flat export. `existingPath` (reprocess) and `vaultAutoFilingEnabled: false` skip classification. The decision is recorded in `manifest.processing.vaultFiling`.
